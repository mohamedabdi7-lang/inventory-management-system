# Inventory Management System

## Project Description

This project is a Flask-based REST API for managing inventory items.

The system allows users to:

- View all inventory items
- View a single inventory item
- Add inventory items
- Update inventory items
- Delete inventory items
- View low-stock items
- Retrieve products from an external API
- Add products from an external API to the inventory
- Interact with the system through a command-line interface (CLI)

## Technologies Used

- Python
- Flask
- Requests
- Pytest
- Fake Store API
- Git and GitHub
